# Security policy

Reskin changes icons on people's PCs, so reports about its security matter a
lot. If you find a vulnerability, please report it privately through
**[GitHub's private vulnerability reporting](https://github.com/KarimEidou/Reskin/security/advisories/new)**
rather than in a public issue, with the steps to reproduce it if you can.

Security fixes go into the latest release, which is always at
<https://github.com/KarimEidou/Reskin/releases/latest>.
